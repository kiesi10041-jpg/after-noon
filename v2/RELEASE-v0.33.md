# 12:00 v0.33.0

- 동일 남성 주인공을 기준으로 투명 2D 행동 애니메이션 12종(각 4프레임), 신규 아이템 누끼 8종, 동물 공격·방어·우회 결과 그림 8종 적용.
- 진행창은 현재 장소를 유지한 작은 오버레이. 이미지 준비 후 진행, 기본 2.6~7초, 빠르게 보기는 해당 작업만, 저장 쓰기 간격 2초로 조정.
- 장거리 지도의 배경 글자와 클릭 지점 중복 제거, 미확인 지점 가독성 개선, 주변/장거리 메뉴 통일. 참고용 실제 역 목록과 예약 출발 선택 제거.
- 근거리 도보·자전거 이동의 피로 누적, 출발·귀환 같은 계산 사용. 휴식·수면으로 누적 피로 회복.
- 긴장 수치에서 원인과 대처 바로 확인. 소지한 책 다시 읽기·주변 정리, 씻기 및 위험 원인 해소의 안정 효과. 반복 사용 제한.
- 섭취는 가방·냉장고·수납장으로 통일. 개봉한 물과 조리 음식도 냉장고에서 사용. 생활 메뉴는 재배·빗물 관리·돌봄. 거처에는 조리 공간 제공.
- 냉장고·수납장·재배 아이콘 구분, 장착 장비와 가방 물품 구분.
- 기존 수집기와 호환되는 상태 기록: 동물 대응, 부상, 몸 상태, 재배·사육, 반려동물, 기본 능력, 이동 피로, 긴장 완화. 기존 플레이 횟수·행동 횟수에는 상태 기록 중복 가산 안 함.
- 기존 저장 파일 및 Google Sheets 원본 events/runs/players 유지. 신규 시트 ‘생존 분석’·‘기록 항목’ 추가. 과거 미수집 상세 정보는 소급 복원하지 않음.

검증: Node 테스트 208개 통과. 신규 WebP 28개 전체 프레임 디코딩·아이템/캐릭터 alpha·정적 이미지 참조 검증.
