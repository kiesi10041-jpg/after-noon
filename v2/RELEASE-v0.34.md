# 12:00 v0.34.0

- 수색은 진열대·수납장·공구·의약품·책장·잔해·주변 관찰을 구분한다. 차량용 그림도 별도 준비했다.
- 공통 인물 기준을 유지한 투명 배경 4프레임 에셋 8종을 추가했다. 같은 캔버스 크기와 바닥 기준을 적용한다.
- 화면 전체를 어둡게 덮는 행동 팝업을 작은 고정 진행 영역으로 변경했다.
- 섭취·대기·휴식 1.5초, 수색·이동 2초, 독서 2.8초, 정비 등 2.6초. 게임 속 소요 시간과 완료 시 보상 처리 원칙은 유지한다.
- 동물 만남에 수색을 계속하는 비접촉 선택지를 추가했다. 큰 동물은 시간 비용을 지불해 우회한다.
- 고양이·새·고라니에게 공통 공격 선택지를 표시하지 않는다. 고양이 관찰과 개의 태도에 상황별 문장을 적용한다.
- 야생동물은 하루 최대 2회, 전역 6시간 간격, 동일 장소 48시간 재등장 제한을 둔다.
- 동물 그림은 도착 전 만남으로 표시한다. 두고 온 반려동물 후보는 재방문 시 수색을 막지 않고 장소의 선택 버튼으로 재회한다.
- 기존 기록 수집 형식은 유지하고 새 행동 이름의 관리자 표시를 추가했다.

검증: 217개 테스트 통과. 모션 파일 32프레임 디코딩·투명도·경로 확인.
실제 iOS/PC 브라우저 화면 검증은 이번 환경에서 수행하지 못했다.
