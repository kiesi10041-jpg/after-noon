# v0.13 변경 내용

- 튜토리얼 흐름: 물과 포장 식량 확보 → 중앙역에서 열차 운행 중단 확인 → 가족 집 방문
- 교통카드와 지하철 운행 기능 제거. 중앙역은 정전 후 탐색하는 장소로 유지
- 가족 집은 도보로 방문할 수 있으며, 자전거는 3일째부터 동네의 정해진 탐색 장소 중 하나에서 발견
- 식사·수분·체온을 유지하고 잠들면 8시간 후 건강 8 회복
- 구급약은 가방에서 사용해 건강 18, 오한 18 회복
- 잠자리의 하루 마감 기록에 건강 회복 방법과 악화 조건 안내
- 기존 저장 데이터에서 교통카드와 지하철 이동수단 제거, 도보로 전환
