# v0.28.0 – 회차별 준비와 여정

- 새 기록은 동일한 총합 12의 5개 능력치를 시드에 따라 배분한다. 정비·재배·응급관리·길찾기·생활 생존 숙련은 별도로 저장한다.
- 실물 책은 가방/현 위치 보관함에 있을 때만 두 차례 읽을 수 있다. 실제 작업 및 하루 한 번의 분야별 실습으로 경험을 쌓는다. 같은 작업 반복으로 무제한 상승하지 않는다.
- 지도 자료 확인 → 인접 경로 후보 → 진입로 조사 → 구간별 이동을 적용했다. 가족 집 위치를 기억해도 처음부터 직행할 수 없다. 장거리 귀환도 거점별로 진행한다.
- 지역마다 주변 시설 구성이 다르다. 서점, 숙박시설, 관리실, 창고, 주택, 약국, 텃밭 등을 연결했다. 책·물자·상태는 시드로 결정하며 재접속/재조사로 재생성하지 않는다.
- 초기 생활권에 식수·식품·기초 공구 획득 가능성을 검사한다. 특정 편의점의 물자 종류와 수량을 고정하지 않는다. 잠긴 수납공간은 다른 접근 방법이 필요하다.
- 식품은 장소 생성 때 정해진 기한을 가져오며, 획득하거나 내려놓는 행동으로 기한을 연장하지 않는다.
- 정비 지식 없이 자전거를 바로 확보하는 경로를 제거했다. 심한 손상은 정비 부품을 요구하고 천은 제한된 응급 수선에만 쓴다.
- 재배에는 기초 지식, 시간 경과, 물주기, 기온이 필요하며 방치하면 죽는다.
- 한 계절 15일, 한 해 60일. 계절 경계 전 기온 변화와 거리 그림을 반영한다. 기존 저장은 이전 계절 위치를 보존하는 오프셋을 사용한다.
- 새 배경 6개: 서점, 교량 보행로, 손상 객차, 여름/가을/겨울 거리. 각각 독립 WebP 파일이다.
- 메뉴의 여정과 목표/경험과 읽을거리에 진행 기록과 기술을 모았다.

## 검증 범위와 한계

기존 회귀 검증 및 신규 세계·능력·학습·이동·기한·계절 테스트를 실행한다. 회차 전체의 실제 플레이 시간/도착일 분포는 베타 플레이로 추가 조정해야 한다. 도로 거리는 게임용 단순화이며 현실 길 안내가 아니다. 생성 배경은 장소 분위기를 위한 삽화이며 정확한 지형도/시설 도면이 아니다. 모든 지역 시설의 개별 배경을 새로 만든 것은 아니며 성격이 맞는 기존 독립 배경도 함께 사용한다.
