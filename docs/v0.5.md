# 12:00 v0.5

## Implemented
- Persistent scene interface; PC split stage, mobile stacked stage; separate modal bag/settings/work/bed controls.
- 12 stamina, action-driven clock, independent movement/search/return cost. Midnight changes date without refilling stamina.
- Home stock and carried supplies separated; tools and flashlight must be packed.
- Night search surcharge without light, battery drain, forced return or shelter when exhausted.
- Illustrated loot cards, separate day/night apartment art.
- Existing v2 saves migrate once; items retained, old action points scaled by four.

## Validation
29 automated checks including 12 journey-specific tests. Browser checks at 390px width: pack water/flashlight, sleep to 20:30, night trip to neighbor, light/search/take/return. Desktop layout inspected. No physical iPhone test performed.

## Assets
Built-in image generation used.
- assets/home-modern-v5.webp: contemporary Korean apartment, bed/window on left, steel entry in center, fridge and white laminate kitchenette on right, sewing table foreground; muted ink/watercolor, no baked-in supplies or interface.
- assets/home-night-v5.webp: edit same composition to power-outage night; remove sunlight, dark exterior buildings, weak cool moonlight; identical furniture and framing.

## Remaining limitations
Other locations reuse existing art with night lighting filters. Equipment cards use interface symbols. Season-specific environments and broader event variety remain unfinished. This is a playable development build, not a finished balance pass.
