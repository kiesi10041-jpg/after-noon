# 12:00 관리자 — Apps Script 공개 조회

URL: https://kiesi10041-jpg.github.io/after-noon/admin/

Google Cloud·OAuth 클라이언트·카드 등록 없이 기존 Apps Script 웹앱으로 조회합니다. 이는 소유자가 요청한 **공개 조회 방식**입니다. URL을 아는 누구나 플레이어 이름과 게임 기록을 읽을 수 있습니다. URL의 비공개 유지는 인증을 대신하지 않습니다. 원본 시트의 편집 권한은 공개하지 않습니다.

## 딱 한 번 연결

1. 관리자 사이트 → 연결 설정 → **수집기 코드 복사**.
2. 기존 구글시트 → 확장 프로그램 → Apps Script.
3. Code.gs의 전체 코드를 복사한 코드로 교체하고 저장.
4. **배포 → 배포 관리 → 기존 웹 앱 → 수정(연필) → 버전: 새 버전 → 배포**.
5. 관리자 사이트 새로고침 → **시트 불러오기**.

기존 /exec 주소가 config.js에 입력돼 있습니다. 새 프로젝트나 새 배포는 만들지 않습니다. 기존 SHEET_ID 설정을 보존하므로 setup을 다시 실행할 필요가 없습니다. 기존 게임의 저장 URL도 바꾸지 않습니다. 기존 웹앱은 소유자 계정으로 실행, 모든 사용자 접근이 가능한 배포 설정을 유지합니다.

## 데이터

관리자에서 `{schema:1,action:'admin_read'}`를 text/plain POST로 보내면 기록 스냅샷을 반환합니다. 기존 기록 추가 POST는 그대로 유지됩니다. 이벤트를 기준으로 플레이어·회차 통계를 집계합니다. 원본 profile_id는 이름+4자리 번호에 기반하므로 공개하지 않고 `player_000001` 형태의 별칭으로 대체합니다. 동명이인과 반복 회차는 구분됩니다. 별칭은 원본 이벤트의 첫 등장 순서이므로 로그 행을 재정렬/삭제하면 달라질 수 있습니다. PIN 원문은 수집하지 않습니다. 화면 해상도·details는 공개 응답에서 제외합니다.

최대 50,000건 전체 스냅샷이며 한도를 넘으면 부분 집계를 표시하지 않고 CSV를 안내합니다. 파일은 현재 브라우저의 메모리에서만 분석합니다. 자동 갱신은 명시적으로 켰을 때 60초마다, 탭이 보일 때만 실행합니다. 오류 시 자동 갱신을 멈추고 마지막 성공 시각을 유지합니다. 조회 전용으로 원본 삭제·수정 기능은 없습니다.

공개 조회를 중단하려면 수집기 상단 `PUBLIC_ADMIN_READ=false`로 변경하고 기존 배포를 새 버전으로 업데이트합니다. 게임의 기록 저장은 계속 작동합니다. 시트 자체를 '웹에 게시'하거나 공유 권한을 변경할 필요가 없습니다.

기존 OAuth 버전의 설정은 사용하지 않습니다. 연결 설정은 `noon.admin.publicConfig`에 주소만 저장합니다. 데이터·인증값은 GitHub에 포함하지 않습니다. collector.txt는 Code.gs 복사용 텍스트이며 실제 수집/조회는 Google에 배포한 코드가 실행합니다.

## 진행 점검 표시

- 행동 제한: 기력·가방·조명·재료 등 확인 가능한 조건으로 중단된 기록.
- 판정 확인 필요: 결과를 확정할 수 없는 기록. 0.31.0에서 물품 획득·이동을 잘못 분류한 기록을 포함하며, 성공으로 소급 수정하지 않습니다.
- 패닉·실수: 게임 내 불이익 이벤트. 행동 제한과 따로 표시합니다.
- 사망 회차: 사망 이벤트가 수집된 회차만 집계합니다.

표는 장소·행동·사유별로 묶고 건수/고유 인원/회차를 구분합니다. '최근 회차 보기'에서 전후 상태를 확인합니다. 0.31.1부터 물자·기술 등의 변화도 기록 결과 판단에 반영하고, 이전 안내 문구를 다른 행동의 실패 이유로 재사용하지 않습니다. 원본 수집 스키마는 유지되므로 Apps Script 재배포는 필요 없습니다.
