# 12:00 플레이테스트 관제실

GitHub Pages용 조회 전용 관리자 대시보드. `/after-noon/admin/`에서 사용합니다. 별도 서버·빌드·유료 호스팅이 필요 없습니다.

## 현재 상태

웹 화면과 CSV 분석은 즉시 사용 가능합니다. Google 실시간 조회는 **소유자가 OAuth 웹 클라이언트를 생성하고 ID를 입력한 뒤** 사용할 수 있습니다. 기존 Apps Script 기록 수집 URL에는 조회 기능을 추가하지 않습니다. 게임 플레이와 수집기는 변경하지 않습니다.

## 빠르게 실제 데이터 보기

1. 비공개 Google Sheet의 `events` 탭 선택.
2. 파일 → 다운로드 → 쉼표로 구분된 값(.csv).
3. 관리자 페이지 → CSV 가져오기 → 파일 선택.
4. 플레이어 검색 → 회차 상세에서 상태 추이와 행동 흐름을 확인.

CSV는 브라우저 안에서 처리하며 서버로 업로드하지 않습니다. 원본 전체가 아닌 일부 CSV를 가져오면 해당 파일에 포함된 범위만 집계됩니다. events CSV가 있으면 이를 기준으로 회차·플레이어를 재집계하고 event_id로 중복을 제거합니다. runs·players만 가져오면 행동 타임라인은 표시되지 않습니다. players만으로는 회차를 분석할 수 없습니다.

## Google 실시간 조회 설정 (한 번)

1. Google Cloud Console에서 프로젝트 생성/선택.
2. Google Sheets API 사용 설정.
3. Google Auth Platform의 Branding/Audience/Data Access 설정. 외부 테스트 앱이라면 테스트 사용자에 본인의 Google 계정 추가. 읽기 전용 Sheets 범위 사용.
4. OAuth 클라이언트 생성 → 유형 `웹 애플리케이션`.
5. 승인된 JavaScript 원본: `https://kiesi10041-jpg.github.io` (경로·끝 슬래시 없이). 다른 도메인이면 실제 origin 등록. 팝업 토큰 모델이라 redirect URI는 쓰지 않습니다.
6. 발급된 `…apps.googleusercontent.com` 클라이언트 ID를 관리자 화면의 연결 설정에 저장.
7. Google로 연결을 눌러 소유자 계정에서 승인.

비공개 시트 접근 권한이 있는 계정만 조회할 수 있습니다. 별도의 앱 내부 이메일 허용목록을 보안 경계로 사용하지 않으며 Google의 시트 ACL을 그대로 사용합니다. Google Cloud 테스트 사용자는 추가로 제한합니다. 조회 권한 범위는 `spreadsheets.readonly`이며, Google 정책상 해당 계정의 Sheets 읽기 범위입니다. 앱은 설정된 한 시트만 요청합니다.

클라이언트 ID와 시트 ID는 공개 식별자이며 비밀키가 아닙니다. 클라이언트 secret·API 토큰·PIN·플레이어 데이터는 코드에 넣지 마세요. 토큰·불러온 데이터는 메모리에서만 보관하고 새로고침/탭 종료 시 사라집니다. 연결 설정만 localStorage에 저장됩니다. '데이터 비우기'는 로컬 화면을 비우고 진행 중 응답도 무효화하며 Google 권한 자체를 철회하는 기능은 아닙니다. 권한 철회는 Google 계정의 서드 파티 연결에서 진행합니다.

상단 60초 자동 갱신은 명시적으로 켰을 때만 작동합니다. 인증 만료 시 재연결이 필요합니다. 마지막 성공 조회 시각을 표시합니다. `생존 기록`은 접속 중/온라인 상태가 아니라 마지막 수집 시점에서 사망 기록이 없다는 뜻입니다. 목표 숫자 quest는 현재 게임 스키마 기준입니다.

## 기능

- 전체 규모·회차 추이·목표 진행·장소·패닉·실수 집계.
- 이름/회차 ID/기간/게임 버전/생존 상태 필터.
- 동명이인 구분, 플레이어별 회차 탐색.
- 회차 건강·수분·긴장 추이 및 최근 250개 주요 이벤트, 전체 회차 CSV 내보내기.
- 전체 이벤트 종류/조건 미충족 필터, 페이지 이동, 필터 결과 CSV.
- 조건 미충족 장소 및 수집된 사망 원인 비교.
- 명확히 표시된 가상 데모. 데모와 실제 데이터는 교체되며 섞지 않습니다.
- 모바일 메뉴/가로 스크롤 표/상세 다이얼로그.

원본 삭제·수정은 제공하지 않습니다. 이벤트가 회차 집계의 근거라 무심코 삭제하면 통계가 달라지기 때문입니다. 관리 범위는 검색·필터·분석·내보내기입니다. 최대 라이브 조회는 events 50,000건, runs/players 각 10,000건. 한도 도달 시 부분 집계를 표시하지 않고 전체 CSV를 안내합니다.
