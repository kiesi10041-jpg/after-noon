# 12:00 — 정오

한국의 도시에서 정오에 모든 사람이 사라졌다. 남겨진 물자를 모으며 첫 30일을 버티는 모바일 웹 생존 게임. **v0.1.0 플레이 가능한 첫 챕터**입니다.

## 플레이

거점에서 물을 비축하고 가방을 챙깁니다. 지도에서 장소를 선택하고 주변을 관찰한 뒤 물자를 회수합니다. 귀환 후 식사·휴식·보수, 밤에는 수면으로 다음 날을 준비합니다. 선택한 행동에만 시간이 흐릅니다.

- 매 회차 물자, 위험, 이동 경로, 날씨, 전기·수도·통신 중단일 생성
- 물건 무게 / 거점 보관함 / 현장에 남긴 물자 / 보수와 빗물 수집
- 긴장·기력·부상, 가족의 집 방문, 사망 및 첫 달 생존 기록
- 기기 내 자동 저장, JSON 백업·복원. 계정·광고·서버·분석 추적 없음
- 모바일 터치와 키보드, 팝업 초점 관리, 시스템 동작 감소 설정 지원

## 실행 및 검증

정적 HTTP 서버로 이 디렉터리를 제공합니다. ES modules를 사용하므로 파일을 직접 더블클릭하는 file:// 실행은 지원하지 않습니다.

```sh
npm test
python -m http.server 8000
```

GitHub Pages: Settings → Pages → Source에서 **GitHub Actions** 선택. main에 푸시하면 테스트 후 배포됩니다. 배포에는 GitHub Pages 설정과 Actions 권한이 필요합니다.

## 파일

- `engine.js`: 결정론적 시드, 자원·시간·이동·사건 규칙
- `app.js`, `styles.css`, `index.html`: 반응형 UI, 저장, 접근성
- `assets/`: 프로젝트에서 생성한 일러스트의 WebP 최적화본 (합계 약 0.95 MB)
- `tests/`: 엔진의 자원·저장·생성·종료 검증

## 범위와 후속 작업

현재는 첫 30일 알파 버전입니다. 겨울, 장기 농사, 연료 노후화, 야생동물 전투와 추가 지역은 미구현입니다. 삽화 일부는 장소 간 공유됩니다. 인프라 붕괴 날짜는 게임을 위해 압축한 가상의 지역 조건이며 실제 예측이 아닙니다. 식수와 부상 처리는 단순화된 게임 규칙입니다. 균형은 실제 플레이 피드백으로 조정할 예정입니다.
